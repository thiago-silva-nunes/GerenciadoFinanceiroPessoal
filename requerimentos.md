# GerenciadoFinanceiroPessoal
Gerenciado de Finanças pessoais feito em java 

## Obejtivo

Desenvolver um sistema aonde seja possível ter o controle das finanças pessoais, bem como ter uma visão em dashboard dos dados para poder ser feito analises 

----------------------------------------------------------

## Usuários do Sismta 
- Admnistrador 
- Usuário

## Problemas Identificados: 
- Falta de local para registro de gastos e receitas 
- Falta de visão das finanças 
- Dificuldade para analisar as finanças e tomar decisões
